# Ranger interactive magic-card preview — 3 November 2026

Dave asked to try a six-card interface for one hero. The separate playable preview is at `preview/magic-cards/`: Aimed Shot, Hunter's Mark and Volley above Potion, Heal and Heart Change. It opens on the six physical miniatures. Tapping a miniature grows it into a full card; selection and Use are on the card. Cards returns to the deck. Battle is a lightweight navigation mock whose purple Magic Powers button reopens the deck.

Aimed Shot reserves magic by tapping purple triangle spaces, then Use spends it and rolls the chosen dice. Hunter's Mark selects the mark before Use. Volley lets the player select the next charge space or a stored die to release, respecting the existing charge-or-use rule. Potion highlights the selected bottle; Use slides that chit off, heals, and returns to the deck. Heal selects the exchange; Heart Change selects a direction before Use. Costs, dice, charges, health, limited uses, potions and heart rules use the existing released engine. The demo begins with a fresh in-memory Ranger, 12 magic, injured health, two potions and one stored Volley charge to make the interactions reviewable. Reset creates a new demo. No saved hero is read or written; no production battle UI is changed.

Validation: `npm test` 564/564. `preview/magic-cards/check.mjs` runs against the local server and covers 390×844, 430×932, 375×667 and 375×548, all six card layouts and actions, charge and release, potion selection/consumption/slide, heal, heart change, real engine costs, the miniature-to-card animation, cancellation without spending, battle navigation, no localStorage mutation and no page/network errors.
