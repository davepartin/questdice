Illustrative numbers, not balanced. The game does not work this way today (see ROSTER.md / ladder.html for what it rolls).

Proposal (Dave): faces 1-4 are the same on every size, 5-6 the same on d6/d8/d10, 7-8 on d8/d10, so a bigger die only adds faces (glow = the faces a size adds; shapes follow the progression 1-4 triangles, 5-6 squares, 7-8 diamonds, 9-10 kites). The metal sets how many bonus icons sit on the same base numbers: Bronze few, Silver more, Gold most. Diamond would be a fourth tier (not shown). Base numbers: the released Bronze Dagger d10 (r0 b1 r1 r3 r3 r5 r5 r7 r7 r9), which already nests without breaking "a dN never shows more than N". Larger sizes are dimmed as locked, with no prices.
