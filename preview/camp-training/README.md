# Camp training playtest

Open this folder through GitHub Pages. It uses the current release assets through a relative base URL, with a separate `preview-camp-training` save namespace and no cloud or online tables. `main.js` enables the candidate only for this exact preview pathname. Root play remains unchanged.

Candidate ranks: +4 maximum health (50/100/180 gold), +1 starting magic (75/150/250), +2 capacity (40/80/140), one rank per act. These prices require the matched campaign study in CAMP-02 before release. Heart 4 remains +2 gold.
